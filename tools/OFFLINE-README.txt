Reflexive Thematic Analysis Canvas — Offline edition
==========================================

This edition works without an internet connection. All libraries are bundled.

How to start
  1. Extract the whole ZIP file to a folder (do not open the files from inside the ZIP).
  2. Double-click  ta_canvas.html  (Chrome, Edge or Firefox recommended).
  Keep ta_canvas.html next to the  app/  folder; the app needs both.

Your data
  - Your work is saved inside the browser on this computer (IndexedDB). Nothing is uploaded and no AI is used.
  - Copies of the app opened from different places (another folder, a web address) keep SEPARATE data.
    To move a project, or to share it with another computer or browser, use Backup (top bar) and
    Menu > Restore backup.
  - The backup .json contains the full text of your documents: store it like raw data.
  - Clearing the browser's site data removes the project. Make a backup at the end of each session.

Try it
  - samples/ contains fictional files in every supported format (.txt, .csv, .docx, .doc).
